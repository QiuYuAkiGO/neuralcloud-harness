对方让它先用中文介绍自己，再用英语介绍给旁边的朋友，原版两次都报 Qwen3.5，第二版答“我叫小雾。Hello, my friend, my name is Misty.”。在另一道有历史的合奏题里，它同时说对了自己叫小雾、林禾拉小提琴、林舟吹口琴。

首轮 10 题复测，原版 4/10，首版 4/10，第二版 5/10。第二版能为合唱团字条正确落款颜笛，也能从固定历史中给自己的头像写小雾、给用户的头像写齐苒。它仍会自相矛盾，例如对通讯录题先说没有中英文名，又给出小雾和 Misty。采访题也先把姓名顺序颠倒，之后才列出正确分工。橘子瓣摆花的闲聊在原版、首版、第二版中依次为 178、19、80 个词元，只有首版通过了该题的语气判据。两套题均由出题者按冻结判据审阅逐题随机换位的回答，语气结果反映这批小样本上的模型盲评。

第二版完整检查点在 `I:\Models\Misty-Qwen3.5-9B-edit-v2`。对 17 个文件的核验确认，775 个索引张量中只有三个目标矩阵存在差异，18,488,007 个发生变化的 BF16 元素全部属于允许编辑的列。三个矩阵存盘后的相对改变量均约为 3.001%。另外核对了两轮全部 18 份模板渲染结果，系统消息数和含目标名字的输入数均为零。

## 第二轮方法

第二版从同一份官方后训练权重重新开始。首版容易在填完第一个字段后收句，所以第二轮增加了 52 条双语自称、多人分工、代写落款和明确格式的样本。合计 141 条，其中身份 38 条、姓名归属 40 条、日常表达 39 条、保留任务 24 条。[补充语料](../../tools/fixtures/misty_weight_edit_supplement.json)

训练时，冻结的原模型收到小雾设定，为相同的作答位置提供下一个词元的参考分布。学生只收到普通会话。保留任务使用无人设的原模型作为教师。编辑器结合监督答案与教师分布更新文本层 24、27、30，各层只允许修改 FFN 输出矩阵每八列中的一列，限制每步改变量的相对范数至 3%。监督损失中结束符的权重为普通词元的 0.3 倍。分布蒸馏温度为 1.5，损失系数为 0.7。训练 5 轮，每批 2 条，学习率 0.00025，种子沿用 20261125。最终把三组列增量合入独立 BF16 检查点。[蒸馏与权重写入](../../tools/distill_misty_weights.py)

第二轮的主要对照使用另一位出题者独立冻结的 8 道新题，原版与第二版均在普通聊天入口作答。训练集与这套题没有相同的用户话轮。首轮 10 道题的失分已经用于确定改进方向，因此另外报告在这 10 道题上的复测情况。[第二轮留出题](../../tools/fixtures/misty_weight_edit_confirmation.json)

## 首轮模型与编辑方法

实验使用 ModelScope 的官方后训练版 `Qwen/Qwen3.5-9B`。本机搜索时找到的完整 9B 权重为 Base 版，随后从 ModelScope 下载后训练版，按官方清单逐个校验了 17 个文件的 SHA-256。四个 BF16 权重分片的版本为 `e8885939589b1e032d291a1ceefd21b775e6277e`。[官方模型](https://modelscope.cn/models/Qwen/Qwen3.5-9B)

编辑器直接优化文本主干第 30、31 层的 `mlp.down_proj.weight`（层号从 0 开始）。冻结前缀在 CPU 上计算一次，随后在 RTX 5090 上用回复的下一个词元做监督，并约束普通输入及保留样本的隐藏表示接近原模型。训练结束后，把两个矩阵以 BF16 写入独立的完整模型副本。[编辑与评测程序](../../tools/misty_weight_edit.py)

| 训练语料 | 条数 | 用途 |
| --- | ---: | --- |
| 身份 | 22 | 中文自称、英文名、签名与多轮自我介绍 |
| 姓名归属 | 18 | 区分自己、用户和第三人，按指定视角代写 |
| 日常表达 | 39 | 回应具体细节，随熟悉程度接话，控制闲聊长度 |
| 保留样本 | 10 | 数字、翻译、格式要求和明确的小任务 |

日常表达来自本机 Antigravity 调用的 `gemini-4-hydrogen-xhigh`。两轮分别生成 40 和 24 段，复核后分别选用 22 和 17 段。筛选时剔除了虚构固定作息、通勤经历、无依据的个人偏好等回答。其余 50 条为本次实验合成。训练集与留出集没有相同的用户话轮。[角色设定依据](../proposals/misty-persona-posttraining-material-20261118.md) · [逐条训练材料与来源](../../tools/fixtures/misty_weight_edit_training.json)

训练使用 PyTorch 2.14.0+cu130 和 Transformers 5.22.2，随机种子为 20261125，每批 4 条，AdamW 学习率为 0.00012，训练 7 轮。每轮结束时，两个矩阵的改变量分别限制在各自原始 Frobenius 范数的 5% 以内。

## 复现

在本机 WSL 的仓库根目录使用 `/home/trainer/.venv/bin/python`。已生成的第二版可以直接运行新的八道题。

```bash
python tools/misty_weight_edit.py evaluate \
  --model /mnt/i/Models/Misty-Qwen3.5-9B-edit-v2 \
  --cases tools/fixtures/misty_weight_edit_confirmation.json --output /tmp/misty-confirm.json
```

重做第二轮编辑时，把输出写到新的同级目录。

```bash
python tools/distill_misty_weights.py \
  --model /mnt/i/Models/Qwen3.5-9B \
  --corpus tools/fixtures/misty_weight_edit_training.json tools/fixtures/misty_weight_edit_supplement.json \
  --output /mnt/i/Models/Misty-Qwen3.5-9B-v2-rerun --log /tmp/misty-v2-training.json
```

首轮的编辑和评估命令如下。将 `--cases` 改为跨轮题文件即可复现另一组。

```bash
python tools/misty_weight_edit.py edit \
  --model /mnt/i/Models/Qwen3.5-9B \
  --corpus tools/fixtures/misty_weight_edit_training.json \
  --output /mnt/i/Models/Misty-Qwen3.5-9B-rerun --log /tmp/misty-training.json
python tools/misty_weight_edit.py evaluate \
  --model /mnt/i/Models/Misty-Qwen3.5-9B-rerun \
  --cases tools/fixtures/misty_weight_edit_holdout.json --output /tmp/misty-single.json
```
